# Custom RoomOS Panel Icons

Custom icons for Cisco RoomOS devices, styled to emulate RoomOS 11, 26, and 27 iconography. Each icon has a standard-padded image and a reduced-padding image, derived from the same editable SVG artwork. Both preserve at least a 5% transparent safe area. Complementary macro code is included to fetch icons and apply them to your extension panels.

The icons were generated by OpenAI Codex and are provided under the [Cisco Sample Code License v1.1](LICENSE).

## Gallery

The GitHub Pages gallery loads [`manifest.json`](manifest.json) in the browser and displays the SVG icons in a searchable grid. Click an icon to open a large preview, or use its link symbol to open the icon’s GitHub folder and access its files.

**GitHub Pages gallery:** [https://ctg-tme.github.io/Custom-RoomOS-Panel-Icons/](https://ctg-tme.github.io/Custom-RoomOS-Panel-Icons/)
The included [Pages workflow](.github/workflows/pages.yml) deploys the site when changes are pushed to `main`.

## Fetch icons

Load `manifest.json` from the GitHub Pages site and find the icon by its name or dashed slug. Use `base_png` for the standard-padded image or `noPad_png` for the reduced-padding image. Standard padding is a good starting point for larger home-screen icons; reduced padding can help the artwork read larger in smaller Control Panel slots. Either type can be used in either location. The RoomOS macro helper downloads the PNG because RoomOS cannot use SVGs in this workflow. Call `install(iconName, { padding })` during macro boot for each icon/padding choice you will use, then `update(iconName, panelId, { padding })` to apply the cached RoomOS icon ID to a panel without downloading again. The `installedIcons` object stores IDs by slug and padding choice; `findInstalled(name, { padding })` matches by slug or display name. The installed ID map lives in macro memory, so install the icons again after each macro restart. The legacy `upload(iconName, panelId, options)` remains available and performs both steps. The gallery's “Fetch an icon” section includes shell `curl` examples and the macro helper code. The helpers are also available in [`macro-functions.js`](macro-functions.js); the published site base URL is embedded in `tmeRoomOSCustomIcons` and each function appends the path it needs. If you fork the repository, replace that base URL with your own Pages site URL. RoomOS's HTTP client must be enabled and permitted to reach the site.

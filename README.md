# Custom RoomOS Panel Icons

Custom icons for Cisco RoomOS devices, styled to emulate RoomOS 11, 26, and 27 iconography. Each icon is padded to render cleanly on RoomOS UI Extension panels. Complementary macro code is included to fetch icons and apply them to your extension panels.

The icons were generated by OpenAI Codex and are provided under the [Cisco Sample Code License v1.1](LICENSE).

## Gallery

The GitHub Pages gallery loads [`manifest.json`](manifest.json) in the browser and displays the SVG icons in a searchable grid. Click an icon to open a large preview, or use its link symbol to open the icon’s GitHub folder and access its files.

**GitHub Pages gallery:** [https://ctg-tme.github.io/Custom-RoomOS-Panel-Icons/](https://ctg-tme.github.io/Custom-RoomOS-Panel-Icons/)
The included [Pages workflow](.github/workflows/pages.yml) deploys the site when changes are pushed to `main`.

## Fetch icons

Load `manifest.json` from the GitHub Pages site and find the icon by its name or dashed slug. Use its `svg` or `png` path to request the asset from the same site for non-macro workflows. The RoomOS macro upload helper always downloads the icon's `png` asset, since RoomOS cannot use SVGs in this workflow. The gallery's “Fetch an icon” section includes shell `curl` examples and RoomOS macro helpers for fetching the manifest and applying an icon to a panel. The helpers are also available in [`macro-functions.js`](macro-functions.js); the published site base URL is embedded in `tmeRoomOSCustomIcons` and each function appends the path it needs. If you fork the repository, replace that base URL with your own Pages site URL. RoomOS's HTTP client must be enabled and permitted to reach the site.

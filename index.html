Using the collection

Fetch an icon

Load manifest.json from this site, find the icon by its name or slug, then use its base_png or noPad_png path to fetch the matching PNG. Standard padding is a good starting point for larger home-screen icons; reduced padding can help the artwork read larger in smaller Control Panel slots. Either type can be used in either location, so check the endpoint result. The manifest is the source of truth for icon names and file locations.

RoomOS macro helpers

Copy the namespaced helpers into a RoomOS macro project. Call install() during macro boot for each icon and padding choice you will use; it downloads the PNG once and keeps the returned RoomOS icon ID in macro memory. Then call update() whenever a panel needs that icon; it reuses the ID without downloading again. The installedIcons object tracks IDs by slug and padding choice, and findInstalled(name, { padding }) looks them up by slug or display name. Use standard padding for larger home-screen icons as a starting point and reduced padding for smaller Control Panel slots when the artwork needs to read larger. Either choice can serve either location. The legacy upload() helper still installs and applies an icon in one call. Install again after a macro restart. The device HTTP client must be enabled and permitted to reach the site.
